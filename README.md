📊 Students’ Social Media Addiction Dashboard

This project analyzes students’ social media usage patterns to understand digital habits, screen time, and engagement behaviors. It includes data on daily usage hours, app preferences, and activity trends such as scrolling, posting, and sharing.

The goal is to identify potential signs of social media dependency and provide insights that help educators, parents, and researchers design awareness programs and digital well-being initiatives.

Key Features:
Tracks daily screen time and active hours
Analyzes engagement levels and content interaction
Highlights risk patterns of excessive usage
Supports digital detox and healthy usage recommendations
